# 震動衝擊測試報告自動化｜第一版

伺服器震動與衝擊測試報告（Excel）的製作工具雛形。從實驗室現場拍照歸位，到產生含照片、判定、問題清單的 Excel 報告，主要流程都能走完。

## 怎麼開始用

1. 打開 `dist/autoreport.html`（用 Chrome、Edge 或 Safari 都可以）。只有這一個檔案，不用安裝，也不用網路。
2. 按「載入示範資料」，就會看到一個做好的示範測試案（照片都是程式畫的假圖，沒有任何真實產品照片）。
3. 依上方分頁 ①～⑦ 走一遍，最後在「⑦ 產生報告」按「產生 Excel 報告」。

## 資料存在哪裡（資安）

- 照片和資料**只存在這台裝置的瀏覽器裡**（IndexedDB），不會上傳到任何伺服器，也不會送到任何 AI 或外部服務。
- 換電腦、換瀏覽器或清除瀏覽器資料，就看不到原本的資料。重要資料請用「匯出專案檔（.zip）」備份到公司 OneDrive。
- 匯出的 zip 裡，照片已依「拍照節點／清單項目」自動命名、分好資料夾，解壓縮後可以直接放 OneDrive 存檔。

## 流程對照

| 分頁 | 做什麼 |
|---|---|
| ① 基本資料與測項 | 填基本資料；選測項（自動展開分項：震動 X/Y/Z、衝擊六面）；設定報告大項（交錯一起做的測項共用一組測試前後照片）；編輯固定文字（預設全部帶入，可刪改）；勾選與增刪拍照清單，可存成機種清單（連同裁切框）下次沿用 |
| ② 時間軸與拍照 | 分項依實際順序排成時間軸（可調整）；在任何分項後面加一組拍照節點；照清單逐格「📷 拍照」或「🖼 選照片」，每格可放多張；會顯示上一組同角度照片做參考；也可整批上傳到「未分類」再歸位；可在現場直接記錄問題 |
| ③ 框選裁切 | 在母圖上畫多個框，每個框是一個零件特寫；框自動套用到其他節點同角度照片，跑掉時拖曳微調（只改那一張）；可疊圖比對對齊；勾「加速規」的框，報告會畫紅框加箭頭連到特寫 |
| ④ 照片回顧 | 選一個角度、裁切框或零件，橫向看它在每個時間點的照片，找出問題是哪個階段產生的 |
| ⑤ 問題與判定 | 逐分項判定（無問題／有問題／依風險跳過）；問題記在分項上，含零件、描述、首次發現的節點、問題頁照片（可選裁切後的特寫） |
| ⑥ 響應圖 | 上傳實驗室的響應 Word 檔，依文件順序抽出所有圖片，指定屬於哪個測項與分項 |
| ⑦ 產生報告 | 系統依時間軸預填每個報告大項的測試前／後節點，使用者確認或改選；不合理時提醒但不阻止；勾選要放的照片；產生 Excel |

## 第一版還沒做的（之後的版本）

- **多人同時編輯**：目前每台裝置各自一份。多人可以各自拍，再用「匯入／合併專案檔」合併（以 id 聯集，不會覆蓋）。正式版要改成存在公司 OneDrive／SharePoint（需 IT 確認 Microsoft Graph 或 Power Apps 權限）。
- **手機現場使用**：程式本身支援手機（版面、相機），但單一 HTML 檔在 iPhone 上無法直接從檔案開啟，需要放到公司內部網頁主機或 SharePoint 網站上。這要先和 IT 確認架設位置。
- **套用公司 Excel 範本**：拿到範本後，改成讀入範本、在固定位置填入、照片多時插入列往下推。
- **輔助功能**：自動辨識零件、自動比對防鬆標記等。若用外部 AI 服務，必須是使用者明確啟用的選用功能，且須先經公司同意。
- iPhone 預設的 HEIC 照片格式部分瀏覽器無法顯示，建議相機設定改成「最相容」（JPEG）。

## 程式結構（給接手開發者／Kiro）

純前端，原生 JavaScript，沒有框架、沒有建置相依（只需要 Python 3 來合併檔案）。

```
src/
  index.html             外殼
  styles.css             樣式
  js/
    00-util.js           共用小工具（建立 DOM、彈窗、選檔、下載）
    10-defaults.js       預設資料：測項庫、10 個母圖角度、零件清單、基本資料欄位
    20-store.js          儲存層（IndexedDB）。介面已抽象化，可換成 OneDrive 版
    30-model.js          資料結構與業務規則：時間軸、拍照節點、建議前後照片、提醒、判定、合併
    40-imaging.js        裁切、縮圖、加速規紅框箭頭合成圖
    50-docx.js           從 Word 檔抽圖片
    60-report-layout.js  Excel 輸出（暫定版面，換範本只改這裡）
    65-package.js        專案檔 zip 匯出／匯入合併
    70-demo.js           示範假資料
    80~87-ui-*.js        各分頁畫面
    99-app.js            分頁切換與啟動
vendor/                  ExcelJS 4.4.0、JSZip 3.10.1（MIT 授權）
build.py                 合併成 dist/autoreport.html
```

修改後重新產生單一檔案：

```
python3 build.py
```

資料結構的完整說明寫在 `src/js/30-model.js` 開頭的註解。重點：

- 原始照片永遠不修改；裁切框存成相對座標（0～1），輸出時才裁切。
- 裁切框定義在「角度」上（母框），個別照片的微調存在 `regionOverrides`。
- 拍照節點掛在「某個分項之後」，所以調整時間軸順序時，節點會跟著分項移動。
- 報告大項的測試前／後節點：沒手動指定時，由 `suggestAssignment` 依時間軸自動建議。
